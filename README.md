# Lost And Found Squad

Build a modern, professional, responsive web application called Campus Lost & Found for college students.

Purpose: Help students report lost belongings and find items reported by other students on campus.

Design: Premium modern SaaS-style interface, clean white background with navy blue and purple accents, attractive navigation, professional typography, smooth animations, rounded cards, responsive on mobile and desktop.

Pages and features:

1. Home page with project name, tagline 'Find what's lost. Return what's found.', search bar, Report Lost Item and Report Found Item buttons, recently reported item cards and statistics for lost, found and returned items.

2. Report Lost Item form: item name, category, description, location lost, date lost, contact information and photo upload.

3. Report Found Item form: item name, category, description, location found, date found, contact information and photo upload.

4. Browse Items page with search and filters by category, location and status, plus Lost and Found filters.

5. Item Details page with photo, description, date, location and contact option.

6. Sample demonstration data for watches, wallets, ID cards, earphones, bags and books.

Make all navigation and buttons functional. Use reusable components. Do not create buttons that do nothing. Start with a working frontend and local demo data. Do not require paid APIs or paid services. Build the complete application, not just a landing page.
